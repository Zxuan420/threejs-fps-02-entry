A round-based tactical FPS in three.js, Counter-Strike-style: two teams, short rounds, a bomb objective, money and a buy menu between rounds, bots that patrol, hold and react, and gunplay where stopping to aim pays. Built by an AI agent for make.fun's "Make the best three.js tactical FPS" bounty, $1,000 in USDC.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome.
